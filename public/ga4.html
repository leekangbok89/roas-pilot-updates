연결 확인 중
GA4 연결저장된 연결을 확인합니다.

Google Cloud에서 내려받은 서비스 계정 JSON 파일을 선택하세요. 인증정보는 이 PC의 Windows 계정으로 암호화해 저장합니다.

속성 ID는 GA4 관리자 → 속성 세부정보의 숫자입니다.

Google Analytics Data API를 사용 설정하고, 서비스 계정 이메일에 해당 GA4 속성의 뷰어 권한을 부여해야 합니다.

연결 계정
최근 연결 확인

GA4를 연결하면 조회할 수 있습니다.

연결을 마치면 유입 데이터를 확인할 수 있습니다.

태그를 새로 설치했다면 일반 보고서 반영에 24~48시간이 걸릴 수 있습니다. 태그 설치 이전의 방문은 소급 수집되지 않습니다.

보고서 확인 사항

    선택한 기간과 범위에서 세션이 조회되지 않았습니다. 최근 설치·UTM 변경 내역은 보고서에 반영될 때까지 기다린 뒤 다시 조회하세요.

    유입 경로 · 광고별

    세션의 소스·매체와 광고 UTM을 기준으로 봅니다.

    소스 / 매체캠페인광고 · UTM세션활성 사용자참여율평균 세션 시간GA4 구매

    광고명은 이 PC에 저장된 Meta 광고 ID와 연결합니다. 같은 사용자가 여러 경로로 방문할 수 있어 행별 활성 사용자를 더한 값은 전체와 다를 수 있습니다.

    첫 방문 페이지

    각 세션에서 처음 열린 페이지별로 비교합니다.

    첫 방문 페이지 경로세션참여율평균 세션 시간GA4 구매

    평균 세션 시간은 방문 전체의 평균 지속시간이며, 해당 페이지를 실제로 읽은 시간과는 다릅니다.

    지표와 조회 범위 이해하기
    • 참여율은 전체 세션에서 참여 세션이 차지하는 비율입니다. 요약은 GA4가 계산한 전체 값으로 표시합니다.
    • Meta 유료 유입은 소스가 fb·ig·an·msg·facebook·instagram이고, 매체가 paid_social·paid social·paid-social·paid·cpc·ppc인 세션입니다. UTM이 없거나 다르면 이 범위에서 빠질 수 있습니다.
    • GA4 구매와 구매매출은 GA4가 수신한 이벤트 기준입니다. 카페24 주문매출과 Meta 귀속 구매매출은 각 화면에서 별도로 확인하세요.
    • 수집 지연, 동의 설정, 데이터 기준점과 집계 방식에 따라 GA4와 다른 서비스의 숫자가 달라질 수 있습니다.
