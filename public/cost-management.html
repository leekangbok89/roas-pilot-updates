원가관리 · 위마망

스마트스토어와 카페24에서 실제 판매한 상품·옵션별 원가를 등록합니다. 모든 금액은 옵션 1개당 원화(KRW)입니다. 저장된 원가는 이익 분석의 기초자료로 사용됩니다.

목록 확인 중

상품명에 ‘위마망’이 있으면 포함, ‘트루버’가 있으면 위마망 분석에서 제외합니다. 두 이름이 없거나 모두 포함된 상품은 직접 분류해야 합니다. 기존 주문 상품정보가 누락된 경우 ‘판매품 가져오기’를 누르세요.

미분류 상품 확인

상품명으로 브랜드를 판별할 수 없습니다. 위마망 상품인지, 분석에서 제외할 상품인지 선택해 주세요. 확인 전에는 위마망 이익에 포함하지 않습니다.

수동 상품·옵션 등록

판매품을 자동으로 불러오지 못했을 때만 사용하세요. 주문 데이터와 일치하도록 상품명과 옵션명을 입력합니다.

원가는 노트북의 로컬 데이터 폴더에 저장되어 일반 프로그램 업데이트로 지워지지 않습니다. 원가를 입력했다고 순이익이 자동 확정되는 것은 아닙니다. 상품별 주문 수량, 수수료, 환불 및 부가세 등을 연결한 뒤 수익 계산에 사용합니다.
