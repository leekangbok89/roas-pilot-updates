쿠팡 API 연결 · 미연결

쿠팡 WING에서 발급한 업체코드·Access Key·Secret Key를 등록하세요. 키는 이 PC의 Windows 계정으로 암호화합니다. API 허용 IP는 실제 인터넷 공인 IP를 사용합니다.

키는 저장 후 입력칸에 다시 표시하지 않습니다. 저장 여부는 위의 연결 상태에서 확인하세요.

저장된 키를 읽어 어제 날짜의 로켓그로스·판매자배송 API 접근을 각각 확인합니다. 진단은 주문 자료와 수집 진행 기록을 바꾸지 않습니다. 인증 문제를 해결한 뒤 기존 수집은 ‘이어서 수집’으로 재개하세요.

저장된 키로 연결 진단을 실행하면 배송 방식별 결과와 확인할 설정을 볼 수 있습니다.

조회 기간과 주문 수집

저장 자료 조회는 API를 호출하지 않습니다. 조회·저장은 최대 1년이며, 7일을 넘는 기간은 백그라운드에서 7일씩 나누어 수집합니다. 그로스는 API에서 제공하는 주문 범위만 조회하며 과거 제공 범위는 별도 확인이 필요합니다. 판매자배송의 반품 완료 주문은 주문 API에서 빠질 수 있습니다. 주문 금액을 확정 매출로 간주하지 않습니다.

최근 1년 주문 저장

대기 · 저장/확인 0/0일·배송방식

그로스와 판매자배송을 최근 365일 기준으로 7일씩 나누어 저장합니다. 과거 저장분은 재사용하고 최근 7일은 갱신합니다. 브라우저를 닫아도 수집은 계속되며, ROAS Pilot 프로그램은 실행해 두세요. 재시작 또는 오류 후에는 이어서 수집을 누르세요. 최초 1년 수집이 끝나면 프로그램을 켤 때 오늘을 포함한 최근 7일만 자동 재확인합니다. 이전 자료는 보존하며 자동 삭제하지 않습니다.

상품현황 엑셀로 원가 매칭

상품현황.xlsx의 옵션ID로 원가·마켓 수수료율·입출고 요금·배송비를 연결합니다. 트루버·위마망 옵션을 집계 대상으로 추가하며 기존에 입력한 원가는 파일 값으로 갱신합니다. 원가 0원은 미확인으로 저장합니다. 상품 조합이 바뀌면 매출·비용을 다시 확인하세요.

집계할 트루버·위마망 상품 선택

주문 수집 후 트루버·위마망 옵션을 체크하고 저장하세요. 쿠팡 수익 분석에서만 두 브랜드를 함께 집계하며, 다른 메뉴는 위마망만 분석합니다. 원가는 관세·수입운송비 등을 포함한 개당 원가를 등록하세요. 원가 미등록은 0원으로 계산하지 않습니다. 추정 수수료는 API 판매금액 기준, 입출고·배송비는 판매수량 기준 참고값입니다. 실제 정산 비용은 매출·비용 입력에서 확인하세요. 선택 상품이 바뀌면 해당 상품 조합의 매출·비용을 다시 확인해 주세요.

매출·비용 입력 및 확인

선택한 트루버·위마망 상품에 해당하는 금액만 입력하세요. 환불 반영 매출은 판매일 기준으로 통일하고 판매자 부담 할인을 반영하세요. 쿠팡 광고비는 실제 사용액과 부가세를 포함하세요. 이미 포함한 비용을 다시 차감하지 않습니다. 수입비를 원가에 넣었다면 입고 운송비에 중복 입력하지 않습니다.

상품 원가가 등록되어 있으면 API 수량 기준 원가를 초안으로 채웁니다. 환불·재입고·폐기·포장비 등을 확인해 수정하세요. 로켓그로스 입출고비에 배송비가 포함되어 있으면 별도 배송비는 0으로 입력하세요. 비용이 없으면 0을 명시하세요.

예상 이익은 확인한 매출과 입력한 비용 범위로 계산합니다. API 주문 합계와 실제 정산금은 구분합니다.
