캠페인별 성과 · 광고비 연결

캠페인마다 한눈에 보기·통합 이익에 반영할 광고비 항목을 선택하고 저장하세요. 저장한 연결은 과거·향후 수집 자료에 모두 적용됩니다. 같은 항목·날짜는 API값을 우선하여 수동 입력과 중복 합산하지 않습니다. ‘광고비 합계에서 제외’해도 이 화면의 캠페인 성과는 유지됩니다.

    선택한 위마망 캠페인의 광고비는 저장한 광고비 연결에 따라 한눈에 보기·통합 이익에 반영됩니다. 검색광고 구매매출은 쇼핑몰 주문매출에 더하지 않습니다. 최근 전환은 이후 변경될 수 있습니다.

    광고비·연결·수집 설정
    검색광고 API 연결

    네이버 광고주센터 → 검색광고 → 도구 → SA API 사용 관리에서 서비스 신청 후 아래 세 항목을 확인하세요.

    연결 정보는 이 PC의 Windows 사용자 계정으로 암호화해 보관합니다. 스마트스토어 커머스API와는 별도의 연결입니다.

    네이버 발급 안내 ↗
    집계할 위마망 캠페인 선택 연결 후 선택할 수 있습니다.

    위마망 캠페인만 체크하고 저장하세요. 체크하지 않은 트루버·기타 캠페인은 광고비·구매·ROAS와 자동 수집에서 제외됩니다. 두 브랜드가 함께 들어 있는 공용 캠페인은 별도로 분리한 뒤 선택하세요.

    노트북의 ROAS Pilot 서버가 실행 중이면 브라우저를 닫아도 수집합니다. 절전·종료 중에는 수집하지 않으며 다음 실행 때 점검합니다.

    위마망 캠페인을 선택한 뒤 자동 갱신을 시작합니다.

    6월부터 과거 데이터 수집·저장

    선택해 둔 위마망 캠페인만 월별로 나눠 저장합니다. 브라우저를 닫아도 서버가 실행 중이면 계속 수집하며, 서버가 종료되면 다음 실행 때 저장된 월부터 이어서 수집합니다.

    위마망 캠페인을 선택한 뒤 수집할 수 있습니다.

    수집이 완료된 월은 다시 더하지 않습니다. 자료가 반환되지 않은 날짜는 0원으로 채우지 않고 미확인으로 표시합니다. 최근 7일 자동 갱신은 별도로 계속 동작합니다.
