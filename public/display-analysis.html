① GFA 광고비·캠페인 예산 자료

네이버 광고센터 캠페인 표를 엑셀로 내려받거나 복사해 붙여넣으세요. 실제 비용은 ‘총비용’, 계획 예산은 ‘캠페인 예산’으로 구분하며 ROAS에는 실제 비용만 사용합니다. 탭으로 복사한 표와 줄바꿈 형태를 인식합니다. 빠진 열은 0으로 추정하지 않고 ‘미확인’으로 표시합니다.

성과를 붙여넣고 분석한 후 저장하세요. 광고비와 캠페인 성과는 프로그램에 함께 보관됩니다.

저장된 GFA 광고비

이전 광고비와 새로 저장한 캠페인 성과의 광고비를 함께 표시합니다. 같은 기간은 한 번만 표시하며, 성과를 삭제하면 해당 광고비도 함께 삭제됩니다. 기간이 겹치면 중복 저장을 막으므로 기존 성과를 불러와 수정하거나 해당 자료를 삭제한 뒤 저장하세요.

② 스마트스토어 전체채널 파일 업로드

네이버 스마트스토어 → 데이터 분석 → 마케팅 분석 → 전체채널에서 지난주 기간을 선택하고 ‘엑셀 만들기’로 내려받은 파일을 넣으세요. 전체채널 파일에는 다른 유입 경로도 포함됩니다. 아래에서 GFA로 비교할 경로만 선택합니다.

파일을 선택하면 날짜·유입 경로를 분석하고, 날짜가 확인되면 중복된 일별 경로를 제외한 나머지를 자동 저장합니다.

날짜가 없는 파일은 실제 내려받은 기간을 직접 지정한 뒤 저장하세요. 일자·유입 경로가 같은 값은 다시 더하지 않고, 신규 행만 누적합니다. 숫자가 변경된 중복 행이나 기간 합계와 일별 행이 겹치면 자동 반영하지 않고 알려드립니다. 수정이 필요할 때는 해당 기간을 직접 다시 저장하세요. ‘직접유입’ 같은 다른 경로를 GFA로 선택하지 마세요.
