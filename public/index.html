      판매 채널별 광고 계정 등록

      Meta 광고 관리자에 표시되는 광고 계정 ID를 입력하세요. 입력한 ID만 이 브라우저에 저장합니다.

      토큰 상태 확인 중…

      저장된 데이터는 즉시 표시하고, 최근 7일은 하루 한 번만 Meta API로 확인합니다. 노트북 서버와 이 웹페이지가 열려 있어야 갱신됩니다. 밤새 저장하는 백그라운드 수집 기능은 아닙니다.

      카페24 주문 API 연결

      카페24 앱의 OAuth 인증을 설정합니다. Meta/네이버와는 독립된 Windows 암호화 저장소를 사용합니다.

      CAFE24

      먼저 실제 운영하는 HTTPS 앱 도메인이 필요합니다. 카페24 개발자센터의 Redirect URI와 아래 주소가 정확히 같아야 합니다. 아직 HTTPS 도메인을 연결하지 않았다면 설정을 보류하세요.

      카페24 연결 상태 확인 중…

      카페24 인증 코드는 발급 후 약 1분 내에 만료됩니다. 앱 외부 공개와 무관한 로컬 관리 도구이므로 개발 환경에서만 인증 절차를 진행하세요. Client Secret, 토큰은 브라우저나 채팅에 저장하지 않습니다.

      카페24 주문·매출 수집

      2026년 6월 1일부터 주문을 수집합니다. 실패한 날짜는 완료로 기록하지 않으며 기존 데이터는 유지합니다.

      상태 확인 중…

      결제일주문 수최초 결제액취소·환불 반영액잔여 매출

      네이버 스마트스토어 API 연결

      위마망 네이버 커머스API 애플리케이션을 연결합니다. Meta 광고 데이터와는 별도로 관리됩니다.

      NAVER API

      애플리케이션 ID 및 시크릿은 브라우저 저장소에 보관하지 않습니다. Windows 사용자 계정 암호화(DPAPI)로 ASUS 노트북에만 저장합니다. 시크릿은 이 채팅에 보내지 말고 여기서 입력하세요.

      연결 상태 확인 중…

      연결 테스트는 네이버 서버로 인증 토큰을 발급받는 단계까지만 검증합니다. 주문 조회·검색 통계 API 권한은 이후 별도 연동이 필요합니다. 등록한 API 호출 공인 IP가 이 노트북의 외부 IP와 같아야 합니다.

      스마트스토어 주문·매출 자동 수집

      네이버 주문 조회 API 권한을 확인하고 상품주문번호 기준으로 저장합니다. 결제 상태와 취소·반품을 구분합니다. 검색어별 유입·매출은 별도 데이터가 필요합니다.

      주문 수집 상태 확인 중…

      결제일상품주문 수최초 결제금액취소·반품 반영액잔여 매출
      아직 수집된 주문이 없습니다.

      원본 주문정보에 고객 이름·전화번호·주소는 저장하지 않습니다. 프로그램이 실행 중일 때만 약 6시간 간격으로 최근 7일을 점검합니다. 백필은 API 제공 범위와 접근 권한에 따라 일부 날짜가 수집되지 않을 수 있으며, 실패 시 상태 메시지에 표시합니다.

      광고비 증액 전후 위마망 매출 분석

      메타 광고비와 스마트스토어·카페24의 위마망 주문 매출을 같은 날짜 기준으로 비교합니다. 미분류 상품은 포함 여부를 확인한 뒤 반영합니다.

      기간을 선택한 뒤 전체 매출 비교를 눌러주세요.
      날짜스마트스토어 매출카페24 매출위마망 합산 매출Meta 광고비자료 상태

      광고비와 매출 증가의 단순 관측 관계만 표시하며, 광고에 의해 발생한 인과적 증분 매출로 확정하지 않습니다. 비어 있는 날은 0원으로 계산하지 않습니다.
