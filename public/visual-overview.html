AI 연결 확인 중

현재 조회 기간의 실제 주문 매출에서 채널별 평균 수수료·전체 광고비·등록된 옵션 원가를 차감한 예상 이익을 기반으로 질문하세요. 배송비·부가세·고정비는 별도입니다.

API 연결은 ChatGPT 구독과 별도 요금이며, 질의 시 광고·매출·원가의 집계 데이터가 OpenAI API로 전송됩니다. 키는 Windows 사용자 암호화로 저장됩니다.

예: 전체적으로 순이익이 극대화된 과거 일예산 구간은 얼마니?

광고 데이터는 Meta API와 ASUS 노트북의 로컬 캐시에서 읽습니다. 조회 오류 또는 구매 이벤트 미수집은 0으로 처리하지 않고 누락으로 표시합니다.
