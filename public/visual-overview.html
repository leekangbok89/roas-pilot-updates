원가 및 매출 데이터 확인 중

—

스마트스토어 매출 × (1 − 스마트스토어 수수료율) + 카페24 매출 × (1 − 카페24 수수료율) − 전체 광고비 − 판매된 옵션 원가 합계. 채널 필터와 관계없이 연결된 전체 Meta 광고비와 입력된 네이버 광고비와 기타 광고비를 차감합니다. 미입력 네이버 항목은 포함되지 않습니다. 기간 합계 입력은 일별 균등 배분 추정치입니다. 미분류·혼합 주문 등이 있으면 확인된 위마망 주문만 부분 집계하여 표시하며, 미확인 주문은 포함하지 않습니다. 부분 이익에서도 연결된 전체 광고비를 차감하므로 전체 순이익으로 해석하지 마세요. 원가나 광고비를 확인할 수 없는 이익은 미확정으로 표시합니다. 실제 세후 순이익은 아닙니다.

브랜드 확인이 필요한 상품

상품명에 위마망만 있으면 포함, 트루버만 있으면 제외합니다. 두 브랜드명이 모두 있거나 모두 없는 상품은 아래에서 직접 선택해 주세요. 기존에 저장한 수동 분류도 아래에서 다시 변경하거나 초기화할 수 있습니다. 선택 전에는 해당 주문을 확인분 매출·이익에서 제외합니다. 같은 주문에 여러 브랜드가 있으면 상품별 결제금액이 확인될 때까지 제외합니다.

왜 순이익이 미확정인가요? · 채널별 누락 진단
원가 연결 안 된 판매 상품·옵션 직접 해결 · 기존 원가 선택 또는 금액 직접 입력

누락된 옵션에 기존 등록 원가를 연결할 수 있습니다. 다른 판매 채널의 원가도 직접 선택할 수 있지만, 실제 동일 상품·사양인지 확인해야 합니다. 확인하지 않은 원가는 자동 적용하지 않습니다.
