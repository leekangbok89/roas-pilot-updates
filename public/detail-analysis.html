이미지 · 영상 이름 관리

현재 자사몰에서 파일 목록을 불러온 뒤 ‘100℃ 가열 설명’, ‘세척 시연’처럼 이름을 붙여 저장하세요. 같은 이름이 통계에도 표시됩니다. GA4 연결 없이도 목록을 관리할 수 있습니다.

영상은 재생창 대신 자동으로 추출한 장면을 표시합니다. 추출이 제한되면 ‘썸네일 등록 / 변경’에서 이미지 또는 원본 영상 파일을 선택하세요. 썸네일을 누르면 원본 영상이 열립니다.

미리보기 · 파일명분석 이름

이름은 상품번호·상세 버전별로 이 PC에 저장됩니다. 이미지 미리보기는 분할 구간이 아닌 원본 전체입니다. 콘텐츠 순서·파일을 바꾸면 상세 버전과 자사몰 설치코드도 함께 바꿔 새 목록을 불러오세요. 처음 불러온 목록은 현재 페이지 기준이므로 그 이전에 페이지 구성이 달랐다면 과거 통계와 대조가 필요합니다.

설치 후부터 데이터를 확인할 수 있습니다

콘텐츠 구간도달 조회도달률평균 화면 체류영상 시작25% 재생50% 재생75% 재생완료율

체류시간은 해당 구간에 도달한 조회당 평균입니다. 여러 구간이 동시에 보일 수 있어 구간별 시간을 합쳐 페이지 시간을 계산할 수 없습니다. 영상 재생률은 화면에 보인 동안 실제 재생한 고유 분량 기준이며, 98% 이상을 완료로 봅니다.

    설치 · 연동 설정

    설정 저장은 자사몰에 코드를 설치하지 않습니다. 아래 코드를 카페24 PC·모바일 상품 상세 스킨에 각각 한 번 적용해야 수집이 시작됩니다.

    GA4 측정 ID는 현재 자사몰에서 확인된 값입니다. 기존 GA4 연결 속성이 이 웹 스트림을 포함하는지 확인하세요. 상세 구성이 바뀌면 버전을 v2, v3처럼 바꾸고 설치코드도 교체하세요.

    Clarity 프로젝트 만들기 ↗

    설치할 상세페이지 열기 ↗
    1. 카페24 디자인 편집에서 실제 사용 중인 PC·모바일 상품 상세 템플릿 하단에 코드를 넣으세요. 기존 Google 태그는 유지합니다. 공통 레이아웃에 넣어도 위마망의 지정 상품에서만 동작합니다.
    2. Clarity 설정 → 설치 → 수동 설치의 clarity.ms/tag/ 뒤 값이 프로젝트 ID입니다. Clarity가 이미 설치되어 있으면 기존 프로젝트 ID를 사용하세요.
    3. GA4 관리자 → 데이터 표시 → 맞춤 정의에서 아래 4개 측정기준과 1개 측정항목을 등록하세요. 범위는 모두 이벤트입니다.
    4. 설치 후 GA4 실시간·DebugView에서 rp_detail_view, rp_content_view 수신을 확인하세요. 이 화면의 일반 보고서 반영에는 24~48시간이 걸릴 수 있습니다.
