# ROAS Pilot 쿠팡 광고 수집 연결 (시험 연결)

ROAS Pilot v2.8.169 이상이 실행 중이어야 합니다. Chrome 확장프로그램 관리에서 개발자 모드를 켠 뒤 이 폴더를 '압축해제된 확장프로그램 로드'로 선택합니다.

확장프로그램을 열고 우선 2026-10-22 하루를 선택해 연결을 확인하세요. 매출성장과 신규구매 보고서는 별도로 요청하며, 기존 요청 목록의 일부 캠페인 파일은 전체 계정 자료로 간주하지 않습니다. 본인이 광고센터에 로그인하고 필요한 인증을 직접 완료해야 합니다.

최근 1년 선택 시 어제까지 최근 365일을 7일씩 나눠 순서대로 요청합니다. 사이트가 허용하는 과거 조회 범위는 실제 화면에서 확인해야 합니다. 요청한 모든 날짜의 파일 저장이 확인돼야 진행률이 올라갑니다. 중단 시 저장된 보고서는 보존됩니다. 새로 시작은 수집 대기열을 새 기간으로 바꾸며 기존 저장 자료를 삭제하지 않습니다.

실제 쿠팡 화면에서의 자동 조회·다운로드 성공은 아직 검증되지 않았습니다. 화면 요소를 확인하지 못하거나 로그인·접근 제한·요청 한도를 만나면 중단합니다. 보안문자나 접속 제한을 자동으로 우회하지 않습니다. 정상 종료 후 '매일 최근 7일 재확인'을 선택했다면 다음 정기 실행에서 해당 기간을 다시 수집합니다. Chrome과 로컬 프로그램이 실행 중이어야 합니다.

쿠키·비밀번호를 읽거나 외부 서버로 전송하지 않습니다. 지정된 광고센터에서 보고서를 요청하고, 일치하는 PA/NCA XLSX 다운로드만 이 PC의 ROAS Pilot으로 전달합니다. 다운로드가 별도 저장 서버를 사용하는 경우 그 서버에 대한 읽기 권한을 Chrome이 추가로 요청할 수 있습니다. 접근 권한을 허용하지 않으면 파일 수집은 멈춥니다.

8MB 이하 XLSX를 지원하며 파일명에 판매자·광고 유형·기간이 필요합니다. 원본 금액과 전환 기간을 보존합니다. PA의 1일·14일 전환과 NCA의 첫구매·재구매 지표는 별도로 저장합니다. 여러 날짜의 합계만 있는 파일은 일별로 분배하지 않습니다. 선택 계정과 파일의 판매자가 다르면 저장하지 않습니다.

자료 수집 성공은 광고비의 부가세 기준·취소/반품 인식일·상품별 원가를 모두 대사한 최종 순이익 확정을 뜻하지 않습니다. 기존 손익 파일의 값을 자동 덮어쓰지 않으며, 별도 수집 연결 화면에서 원본 통계를 확인합니다.
