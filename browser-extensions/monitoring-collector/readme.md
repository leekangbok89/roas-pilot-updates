# ROAS Pilot 일간 모니터링 연결

Chrome 확장프로그램 관리에서 개발자 모드를 켜고 압축을 푼 이 폴더를 불러옵니다. 설치 후 ROAS Pilot의 모니터링 → 수집 연결 화면에서 수집을 시작합니다. 설치는 사용자 Chrome에서 직접 완료해야 하며 프로그램 업데이트만으로 설치되지 않습니다.

셀하에 이미 등록된 상품과 실제 표시된 날짜별 순위·가격·리뷰 수 등을 읽습니다. 셀하 로그인과 이용 권한이 필요합니다. 로컬에서만 추가한 키워드는 셀하에도 등록되어 있어야 순위 기록을 수집할 수 있습니다. 새 상품 등록, 셀하 확장프로그램 설치, 외부 알림 발송을 대신하지 않습니다. 셀하에서 제공하지 않는 과거 날짜를 만들거나 현재 값을 과거로 복사하지 않습니다. 최근7일 모드는 실제 읽은 기록 중 최근7일만 저장합니다.

처음에는 전체 기록 수집으로 연결을 확인하세요. 저장 ACK가 확인된 작업만 완료 처리하며 중지 후 이어서 수집할 수 있습니다. 매일 수집은 사용자가 선택한 경우에만 실행됩니다. Chrome, 셀하 로그인, 로컬 ROAS Pilot이 실행 중이어야 합니다. 로그인·보안문자·접근 제한·화면 변경이 있으면 중단하며 우회하지 않습니다.

상품별로 키워드 탭을 먼저 읽고 리뷰 탭과 네이버 판매량 탭을 차례로 확인합니다. 리뷰는 현재 화면에 실제 표시된 본문만 수집하며 전체 리뷰 이력 수집을 보장하지 않습니다. 셀하 원본 확장프로그램이 필요하거나 본문 구조를 확인할 수 없으면 해당 항목의 제한을 표시하고 확인한 순위 기록은 보존합니다. 네이버의 7일 구매 건수는 관찰한 7일 합계로 저장하며 일별 판매량으로 환산하지 않습니다. 쿠팡 화면에는 판매량 탭이 없어 수집하지 않습니다.

권한은 셀하와 이 PC의 localhost:3000 화면, 대기열 저장·예약·탭·스크립트 실행에 한정합니다. 쿠키·비밀번호·개발자 디버깅 권한은 요청하지 않습니다. 로컬 연결 토큰은 셀하 페이지에 전달하지 않습니다. 자료는 로컬 프로그램에 저장하며 GitHub 또는 다른 외부 서버로 전송하지 않습니다.
